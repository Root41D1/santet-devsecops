# Code of Conduct

Santet DevSecOps is committed to a respectful, harassment-free community.
Contributors must communicate constructively, welcome differing experience
levels, respect privacy, and focus criticism on ideas and code rather than
people. Harassment, threats, discrimination, doxxing, and publishing sensitive
security evidence are unacceptable.

Maintainers may edit or remove contributions and restrict participation when
behavior threatens the community or project. Report conduct concerns privately
to the repository maintainers. Reports will be handled as confidentially and
fairly as practical.
